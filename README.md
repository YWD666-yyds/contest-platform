# 人工智能应用赛项 · 市级初赛平台

依据《人工智能挑战类-人工智能应用-竞赛规则》（2026 年广东省青少年发明创新与科技实践活动暨第七届广东省青少年创新思维及科技实践大赛）开发的市级初赛线上平台。

**赛事主题**：智绘城市 · AI 便民智慧设施
**本届范围**：小学高段组（4—6 年级，3 年级可自愿选报）

## 功能总览

| 端 | 功能 |
|----|------|
| 公众端 | 赛事首页（主题/赛程/创作参考方向）、比赛规则要点、通知公告、成绩公示（排名 + 凭参赛编号查询，管理端一键开关、姓名脱敏） |
| 学生端 | 参赛编号登录、首登强制改密；**知识测试**：限时线上答题（服务端计时、每生题目与选项乱序、自动保存、到时自动收卷、切屏记录佐证、截止前可恢复作答再提交，成绩以最后一次为准）；**智能体实操**：见下 |
| 设计智能体 | 学生工作台「设计智能体」：三步引导（阅读题目要求 → 9 字段设计表单：名称/服务对象/应用场景/角色定位/便民问题/功能技能/知识资料/语气风格/开场白 → 与自己的智能体对话测试并提交任务，合格前可撤回修改）。答题时间结束后配置锁定，转为**体验模式**（可对话展示、供教师现场核验，不计入评审）；LLM 由管理员在「🤖 智能体设置」配置（OpenAI 兼容接口，API Key 加密存储、掩码显示、测试连接按钮） |
| 管理端 | 概览仪表盘、学生管理（批量导入 CSV/单个添加/编辑/重置密码/取消资格/导出）、题库管理（内置高段组 16 题样题，可增改/JSON 批量导入）、赛事设置、智能体设置（LLM + 题目要求）、智能体任务检测与导出、实操考试管理（题目/窗口/两部分成绩权重）、成绩排名（知识测试 ×权重 + 实操得分 合并折算，晋级名额）、公告管理、审计日志 |

**评审方式**：本届不设线上评委端，智能体作品由组委会教师线下评审——平台提供 AI 自动检测（设计完整性 + 对话轮数）+ 管理端人工「合格/需修改」结论记录，知识测试成绩系统自动判分。

## 技术栈

- **后端**：Python FastAPI + SQLite（WAL），仅 3 个依赖（fastapi / uvicorn / python-multipart）
- **前端**：无构建原生 JS SPA + CSS，零外部 CDN 依赖（适合境内网络环境）
- **安全**：scrypt 口令哈希、HttpOnly 会话 Cookie（单点登录）、CSRF 头校验、登录失败锁定、SQL 全参数化
- **部署**：Nginx（静态/限速/gzip）+ systemd（沙箱加固）+ 每日自动备份

## 开发注意事项

- **前端模块版本号**：`index.html` 与所有 JS 模块间的 import 都带 `?v=N` 版本号（生产 Nginx 对静态资源设 7 天强缓存，发布新代码必须整体提升版本号才能让浏览器拉到新文件）。**新建 .js 文件时，其 import 与被 import 的引用链都要同步加当前版本号**，否则会产生第二个模块实例（表现为页面元素重复渲染）。
- 工作台/向导类页面注意函数命名不要与模块级 `render` 遮蔽，否则状态操作后会用过期数据重绘。

## 本地运行（Windows / macOS / Linux）

```bash
cd contest-platform
python -m venv venv
venv/bin/pip install -r requirements.txt
venv/bin/python -m app.seed                  # 初始化管理员 + 样题（幂等）
venv/bin/python -m uvicorn app.main:app --reload --port 8000
```

打开 http://127.0.0.1:8000 → 管理后台 `#/admin`（账号 `admin`，初始密码 `admin@2026`，可用环境变量 `ADMIN_INITIAL_PASSWORD` 覆盖）。

> 数据（数据库）都在 `data/` 目录，删除该目录即可完全重置。

## 测试

```bash
venv/bin/pip install pytest httpx
venv/bin/python -m pytest tests/ -q
```

覆盖 22 项：判分与同分排序、考试全流程（开考/保存/交卷/自动判分/恢复作答）、名单导入（查重/编码）、智能体设计/对话限流/任务提交/管理端检测、LLM 配置不泄露、端到端闭环（导入→考试→智能体→合并排名→公示）。

## 学生名单导入格式（CSV）

```csv
姓名,学校,年级,组别,指导教师
张小明,佛山市实验小学,三年级,高段组,王老师
李小红,佛山市实验小学,五年级,,王老师
```

- 年级支持：一~六年级 / 7-9 年级数字 / 初一~初三 / 高一~高三 / 中职一~三年级
- 组别自动映射：3 年级默认高段组（「组别」列可显式填“高段组”）；4—6 年级默认高段组
- 导入后立即下载**账号单**（含参赛编号与初始密码，仅显示一次），学生首登强制改密
