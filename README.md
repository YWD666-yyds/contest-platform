# 人工智能应用赛项 · 市级初赛平台

依据《人工智能挑战类-人工智能应用-竞赛规则》（2026 年广东省青少年发明创新与科技实践活动暨第七届广东省青少年创新思维及科技实践大赛）开发的市级初赛线上平台。

**赛事主题**：智绘城市 · AI 便民智慧设施

## 功能总览

| 端 | 功能 |
|----|------|
| 公众端 | 赛事首页（主题/组别/赛程/创作参考方向）、比赛规则要点、通知公告、成绩公示（按组别排名 + 凭参赛编号查询，管理端一键开关、姓名脱敏） |
| 学生端 | 参赛编号登录、首登强制改密；**小学低段组**：作品三步提交向导（作品说明≥100字+AI平台标注 → 设计图≥1920×1080 且 ≤20MB → 过程记录1—3张，客户端+服务端双重校验），截止前可撤回修改；**高段/中学组**：限时线上答题（服务端计时、每生题目与选项乱序、自动保存、到时自动收卷、切屏记录佐证、截止前可恢复作答再提交，成绩以最后一次为准） |
| 评审端 | 低段组作品匿名评审队列（缩略图），按规则 7.2 评分表打分（主题契合30/创意构思35/设计表达20/创作过程15）+ 评语，可改分 |
| 管理端 | 概览仪表盘、学生管理（批量导入 CSV/单个添加/编辑/重置密码/取消资格/导出）、题库管理（内置高段16题+中学22题样题，可增改/JSON批量导入）、赛事设置（提交窗口、考试窗口/时长/是否显示分数、公示开关、晋级名额）、智能体设置、智能体任务检测与导出、成绩排名（低段组按平均分+同分依次比创意构思→主题契合→设计表达→创作过程；答题组按得分→用时）、评委账号管理、公告管理、审计日志 |
| 设计智能体 | 学生工作台「设计智能体」：三步引导（阅读题目要求 → 9 字段设计表单：名称/服务对象/应用场景/角色定位/便民问题/功能技能/知识资料/语气风格/开场白 → 与自己设计的智能体对话测试并提交任务，合格前可撤回修改）；题目要求由管理员在后台编辑；LLM 由管理员在「🤖 智能体设置」配置（OpenAI 兼容接口，支持 SiliconFlow/智谱/DeepSeek/通义预设，API Key 加密存储、掩码显示、测试连接按钮）；教师在「🗂️ 智能体任务」查看自动检测结果（设计完整性+对话轮数≥2轮）、完整对话记录，标记「合格/需修改」并导出 CSV；对话出错时向学生展示友好提示（如「请联系老师补全 API Key」），上游错误信息不泄露 |

## 技术栈

- **后端**：Python FastAPI + SQLite（WAL）+ Pillow，仅 4 个依赖
- **前端**：无构建原生 JS SPA + CSS，零外部 CDN 依赖（适合境内网络环境）
- **安全**：scrypt 口令哈希、HttpOnly 会话 Cookie（单点登录）、CSRF 头校验、登录失败锁定、上传魔数校验、SQL 全参数化、UUID 文件名
- **部署**：Nginx（静态/限速/gzip）+ systemd（沙箱加固）+ 每日自动备份

## 开发注意事项

- **前端模块版本号**：`index.html` 与所有 JS 模块间的 import 都带 `?v=N` 版本号（生产 Nginx 对静态资源设 7 天强缓存，发布新代码必须整体提升版本号才能让浏览器拉到新文件）。**新建 .js 文件时，其 import 与被 import 的引用链都要同步加当前版本号**，否则会产生第二个模块实例（表现为页面元素重复渲染）。
- 工作台/向导类页面注意函数命名不要与模块级 `render` 遮蔽，否则状态操作后会用过期数据重绘。

## 本地运行（Windows / macOS / Linux）

```bash
cd contest-platform
python -m venv venv
venv\Scripts\pip install -r requirements.txt     # Linux/macOS: venv/bin/pip install -r requirements.txt
venv\Scripts\python -m app.seed                  # 初始化管理员 + 样题（幂等）
venv\Scripts\python -m uvicorn app.main:app --reload --port 8000
```

打开 http://127.0.0.1:8000 → 管理后台 `#/admin`（账号 `admin`，初始密码 `admin@2026`，可用环境变量 `ADMIN_INITIAL_PASSWORD` 覆盖）。

> 数据（含数据库与上传文件）都在 `data/` 目录，删除该目录即可完全重置。

## 学生名单导入格式（CSV）

```csv
姓名,学校,年级,组别,指导教师,作品名称
张小明,佛山市实验小学,三年级,高段组,王老师,
李小红,佛山市实验小学,三年级,,王老师,智能感应遮阳路灯
```

- 年级支持：一~六年级 / 7-9年级数字 / 初一~初三 / 高一~高三 / 中职一~三年级
- 组别自动映射：1-2 年级→低段组；3 年级默认低段组（「组别」列填“高段组”可自愿选报）；4-6→高段组；7-12→中学组
- 导入后立即下载**账号单**（含参赛编号与初始密码，仅显示一次），学生首登强制改密
