## 一、项目背景与建设目的

### 1.1 背景

依据《人工智能挑战类-人工智能应用-竞赛规则》（2026 年广东省青少年发明创新与科技实践活动暨第七届广东省青少年创新思维及科技实践大赛）及佛山市教师培训 PPT，开发本市级初赛线上平台。

- **赛事主题**：智绘城市 · AI 便民智慧设施
- **赛制**：市级初赛（线上）→ 省级决赛（线下），本平台承载市级初赛
- **参赛对象**：小学低段组（1—3 年级）、小学高段组（4—6 年级，3 年级可自愿选报）、中学组（7—12 年级含中职），个人赛

### 1.2 建设目的

| 痛点 | 平台方案 |
|------|---------|
| 报名信息靠表格收集、易错难汇总 | 管理员批量导入名单，系统生成参赛编号与初始密码，一键导出 |
| 低段组作品（设计图/说明/过程记录）靠微信/邮箱收集，无法核验规格 | 平台提交，自动校验 PNG/JPG、≥1920×1080、≤20MB、说明≥100 字等硬性要求 |
| 高段/中学组线上作答缺少统一入口与计时 | 服务端权威计时、乱序发卷、自动判分、按「得分→用时」排名 |
| 人工统计成绩、处理同分规则易出错 | 严格按规则 7.2/7.3 实现评委平均分与同分排序，自动生成公示名单 |
| 材料真实性难以核验 | 评审端匿名评审、切屏行为记录、伪造文件（改后缀）拦截、审计日志全程留痕 |
| 学生缺乏「用 AI 解决身边问题」的实践载体与老师验收手段 | 新增**设计智能体与任务检测**模块：学生按题目要求引导式设计智能体、对话验证并提交任务，老师在后台自动+人工检测验收 |

## 三、技术架构与安全设计

```
浏览器（原生 JS SPA，零 CDN 依赖）
   │  HTTPS
Nginx（静态直出 / gzip / 登录限速 / 25M 上传限制）
   │  反向代理 :8000
FastAPI（uvicorn × 4 workers）
   ├─ SQLite（WAL + busy_timeout + 索引）
   ├─ Pillow（图片校验 + 480px 评审缩略图）
   └─ LLM 服务（OpenAI 兼容 /chat/completions，管理员配置）
```

**安全设计**：scrypt 口令哈希、HttpOnly 会话 Cookie（单点登录）、CSRF 自定义头校验、登录失败锁定、上传魔数校验防伪造、UUID 随机文件名、SQL 全参数化、API Key 永不回传前端、审计日志。

**服务器优化（Ubuntu）**：静态资源与上传图片由 Nginx 直出（7 天缓存）、SQLite WAL 调优、systemd 沙箱加固（ProtectSystem/MemoryMax/崩溃自愈）、每日凌晨自动备份（保留 14 份）、UFW/HTTPS(certbot) 指引。

## 六、风险与建议

1. **LLM 成本与额度**：学生对话消耗 token，建议在管理后台选用低成本模型（如 glm-4-flash、Qwen2.5-7B），并通过 max_tokens 上限控制单次回复长度；正式使用前先小范围试运行观察消耗。
2. **考试时段并发**：2 核 2G 服务器可支撑千人报名、数百人同屏答题；若单场同屏超千人，把 `contest.service` 中 `--workers` 调为 CPU 核数 × 2。
3. **数据安全**：每日自动备份保留 14 份，建议定期异地下载；正式启用 HTTPS（certbot 一条命令）。
4. **答辩佐证**：考试切屏记录、审计日志仅作佐证不自动判罚，是否认定违规由组委会按规则人工裁定。
